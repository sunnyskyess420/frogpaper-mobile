# FrogPaper Mobile 1.11.1 - release notes

**App 1.11.1 (versionCode 50) · Android 7.0+**

The quick follow-up to the Halloween Edition: the Build screen's options are
now editable, like the desktop app's dropdowns.

## New

- **Type your own value in any Build-screen option.** Every row's picker
  (mode, subject, setting, style, lighting, colour, mood, atmosphere - and
  recipe slots) now has a text field at the top: type anything, tap **Use**,
  and it lands in the prompt exactly as typed. "halloween" as a subject? Go
  ahead. Values you typed show up selected, and opening the sheet again starts
  from your text so you can edit it.
- **Five new builder checks** cover custom values end to end - a typed
  subject, a typed mode with no real mode data, setting prepositions, and a
  custom atmosphere surviving composition with a real mode.

## Notes

- Nothing changes about your existing selections, recipes or wallpapers.
- App checks: 15 suites, 635 checks, all passing. The release APK builds and
  is signed with the FrogPaper release key.
